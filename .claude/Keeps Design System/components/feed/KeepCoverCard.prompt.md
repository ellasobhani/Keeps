Square cover tile for a keep, shown 2-up on the Profile grid. Title sits below the image (never overlaid) with a small lock glyph for private keeps.

```jsx
<KeepCoverCard title="Spring Break 2026" coverSrc={url} isPrivate onClick={openKeep} />
```

Sharp corners (radius none) — matches every media tile in the system. No card border/shadow; the surface-tint placeholder shows only when there's no cover photo yet.
